## 📌 Projects

### 💬 Chatle
A full-stack real-time chat app on the MERN stack, plus a multi-provider AI bot (Groq + Gemini) that actually remembers the conversation. JWT auth, Socket.IO messaging, Cloudinary for image sharing. Broke it in production more than once, learned a lot fixing it.
`React · Vite · Tailwind · Node.js · Express · MongoDB · Socket.IO`

### 🔍 Wholesale Sourcing Research Bot
An AI Telegram bot + dashboard that does supplier research so my family's team doesn't have to dig through group chats and half-remembered links. Handles Khmer and English mid-conversation, and tracks which brands are already verified so nobody researches the same thing twice.
`Telegram Bot API · React · Supabase · Perplexity API · DeepSeekAPI`

### 🎬 Cinemex
A movie review site (live search, category filters, hamburger nav) I built with a team for my web dev course. My first time shipping something where someone else's code lived in the same repo.
`HTML · CSS · JavaScript`
